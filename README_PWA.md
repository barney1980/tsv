# TSV Nettelkamp Handball-Manager – V1.0.0-RC1

GitHub-Pages/PWA-Version für den längeren Go-live-Test.

## Dateien
- `index.html` – vollständige Anwendung
- `manifest.webmanifest` – PWA-Konfiguration
- `sw.js` – Service Worker mit versionsbezogenem Cache
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` – App-Symbole
- `TSV_Logo.jpg`, `Handballfeld.jpg` – benötigte App-Bilder

## GitHub Pages
Die Dateien müssen im Repository-Root des `main`-Branches liegen.
GitHub Pages: `Settings → Pages → Deploy from a branch → main → / (root)`.

Die Pfade sind bewusst relativ (`./`), damit die App auch unter
`https://USERNAME.github.io/REPOSITORY/` funktioniert.
